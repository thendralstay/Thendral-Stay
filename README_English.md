# Thendral Stay — English Guest Register

English-only Indian guest registration PWA template.

## Features
- Guest name, phone, room number and guest count
- Check-in / check-out dates
- ID proof type and optional reference
- Address, room charge and payment status
- Search, edit, check-out, delete
- CSV backup and print / save PDF

## Important
This version stores records in the current browser on one device only. It does **not** sync across phones. Multi-phone sync requires Firebase Authentication, Firestore security rules, configuration, and HTTPS hosting. This is not an APK yet.

Do not store full Aadhaar numbers or ID images. Protect CSV backups because they contain personal information.
